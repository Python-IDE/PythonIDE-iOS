PythonIDE · 网站部署教程

如何用 iPhone 发布 HTML 网站

在 iPhone 或 iPad 上用 PythonIDE 写 HTML，先在本地预览，再部署成公开的 HTTPS 网站。把网址发给朋友，对方用浏览器就能打开。

查看部署步骤 ↓ 看真实作品 ↓

快速开始

从一个 HTML 文件到上线

准备一个带有「部署」标签的 PythonIDE 版本。新建文件和本地预览无需登录；发布和管理网站需要登录 PythonIDE 账号。

  1. 01

    新建或导入 HTML 项目

    点按加号新建 HTML 文件，也可以从「文件」打开已有网页。建议把入口文件命名为 index.html，将 CSS、JavaScript 和图片放在同一个项目目录内，并用相对路径引用，例如 ./styles.css。

  2. 02

    切换到「预览」检查效果

    在「代码」修改页面，切到「预览」检查文字、按钮和图片。带相对路径的项目资源会随页面打包，无需手动压缩或上传 ZIP。

  3. 03

    在「部署」标签发布并复制链接

    点「部署网站」，按提示登录并确认发布。等页面显示「网站已上线」，复制 HTTPS 网址，用浏览器打开核对。以后可以在同一项目更新网站，继续使用原网址。

网站部署常见问题

支持部署哪些文件？可以运行 Python 后端吗？

支持 HTML、CSS、浏览器端 JavaScript、图片、字体等静态文件。部署服务不会运行 Python、Flask、Node.js 或数据库。公开网页的源码和静态资源可被访问者读取，请勿打包密钥或私人文件。

怎么在网站广场展示，或者下线？

在「网站管理」开启「展示在网站广场」，通过审核并保持上线的作品会出现在广场。关闭展示后，原分享链接仍可打开；需要停止公开访问时，选择「下线网站」。

怎样为作品添加封面？

在入口文件的 <head> 内添加 <meta property="og:image" content="./cover.webp">。把不超过 1 MiB 的 WebP、PNG 或 JPEG 图片放进项目，然后更新网站。
