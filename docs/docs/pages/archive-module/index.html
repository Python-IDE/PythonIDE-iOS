archive

原生 ZIP、IPA 等容器的安全检查、解压与创建。

原生 ZIP 检查、列表、解压与创建。适合 .zip、.ipa、.whl、.jar、.apk、.npz 等以 ZIP 为容器的常见格式。

边界：首版只承诺 ZIP 容器，支持 stored 与 deflate。加密条目、未知压缩方法、ZIP64、符号链接和特殊文件会明确失败；不会调用 Python zipfile。普通源路径和所有输出路径都需要 file_system 且必须位于当前 MiniApp 工作区。系统分享页交付的准确 LaunchItem.path 是本次运行的 host-issued 只读输入例外，可直接检查或作为解压源，但不能原地修改。

#模块概览

项说明
导入import archive
适合做什么检查 IPA/ZIP 内容、解压数据包、确定性创建 ZIP
原生实现Swift 中央目录解析 + Compression，无 Python zipfile
支持方法stored、deflate
安全模型路径边界、Zip Slip、绝对路径、symlink、条目/大小/压缩比预算
写入模型先写同目录 staging，完整校验后原子安装目标

#extract

extract(path, destination_path, *, overwrite=False, operation_id=None, **limits)

  • 目标必须是当前 MiniApp 工作区内的目录路径。
  • 不覆盖时，目标存在会抛出 destination_exists。
  • 覆盖时，旧目录会保留到新目录完成全部解压、CRC 与预算检查之后。
  • 失败或取消不会留下半个正式目标；临时 staging 会清理。

#create

create(source_path, destination_path, *, compression="deflate", include_root=False, overwrite=False, operation_id=None, **limits)

参数说明
source_path一个普通文件或目录，或当前 host-issued 只读输入；拒绝 symlink 与特殊文件
destination_path输出 ZIP/ZIP 衍生容器路径
compressionstored 或 deflate
include_root目录源是否包含最外层目录名
overwrite是否在新 ZIP 完成并通过自检后替换旧文件

创建结果具备固定条目顺序、固定 ZIP 时间戳和固定可移植权限。同一目录内容可得到一致的 ZIP 字节。高度可压缩文件若超过安全压缩比，会自动改用 stored，确保创建出的包仍能通过同一解压策略。

#取消

Archive API 是同步调用；需要取消时，在工作线程执行操作并提前提供 ID，另一个线程调用 cancel()：

MiniApp 运行会话停止时，宿主也会自动取消该会话拥有的 Archive 操作；旧会话不能继续提交文件。

#默认安全预算

预算默认及硬上限
条目数500
单条目展开大小64 MiB
总展开大小200 MiB
ZIP 文件大小200 MiB
单条目压缩比200:1

调用者可以调低预算，不能超过硬上限。路径包含 ..、绝对路径、Windows 盘符、反斜杠、NUL、大小写/Unicode 冲突，或文件与目录冲突时都会拒绝整个操作。

#错误码

ArchiveError.code含义
invalid_archiveZIP 结构、大小、CRC 或 local/central header 不一致
unsafe_pathZip Slip、绝对路径或不安全目标
symlink_entryZIP 或源目录包含符号链接
encrypted_entryZIP 条目已加密
unsupported_compression不是 stored/deflate
zip64_unsupported需要 ZIP64；首版不承诺
too_many_entries / entry_too_large / archive_too_large超出预算
compression_ratio_exceeded压缩比超过预算
checksum_mismatch解压 CRC 校验失败
destination_exists未允许覆盖但目标已存在
file_denied路径不在当前 MiniApp 工作区
miniapp_session_expired发起操作的运行会话已结束
cancelled主动取消或会话停止

#常见错误

错误写法后果修正
使用 zipfile.extractall()绕过宿主路径与资源预算使用 archive.extract()
把 LaunchItem.path 当成可写目录外部授权被拒绝只读该输入，输出写入 MiniApp 工作区
把输出 ZIP 放进正在压缩的源目录递归/不确定结果输出到源目录外的同级路径
遇到 ZIP64 或加密 ZIP 后忽略错误用户以为已完整处理展示明确错误并让用户换包
在 AppUI body() 中创建或解压重建时重复执行放进按钮回调或后台线程
