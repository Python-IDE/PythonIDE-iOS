# 用户旅程

## J01 首次成功：从零运行 Python

目标：首次启动后 2 分钟内看到自己代码的结果。

1. 首页 → 右上角 `+` → `Python 文件`。
2. 输入文件名并创建；编辑器打开。
3. 输入或修改样例代码。
4. 点顶部 `运行`。
5. 输出页出现文本/图像/图表；若调用 `input()`，在交互输入框继续。
6. 结果可复制、保存或分享。

分支：启动样例已存在；代码报错；脚本超过 10 分钟；需要第三方包；后台运行关闭。对应 F01、F02、F03。

## J02 迁移现有项目

入口可能为首页 `导入文件`、`连接文件夹`、Files App 打开、Share Extension 或 iCloud 工作区。导入后先确认目标根目录，再根据类型进入编辑、预览、Archive 或 MiniApp 安装。冲突时必须展示重命名/覆盖/取消分支；外部安全作用域丢失时重新授权。

## J03 从错误到修复

运行 → Traceback → 点文件/行号回到编辑器 → 手动修改或 `AI 修复` → 查看 Diff/验证 → 再次运行。若进程无响应，从等待提示选择继续或强制停止。该旅程是高教程优先级、低到中等宣传优先级。

## J04 Agent 安全协作

选择工作区 → 新对话 → 选择模型/批准模式 → 附加文件或描述任务 → Agent 制定计划并请求工具权限 → 用户确认高风险动作 → 查看文件 Diff 与验证 → Apply/拒绝 → 再运行。免费托管额度、BYOK/Pro、离线、权限拒绝和工具失败必须作为 L4 分支。

## J05 脚本到 MiniApp

脚本/文件夹上下文菜单 → `转为 MiniApp`/`打包为 MiniApp` → 选择 Runtime/入口 → 编辑资源与配置 → 运行 → 查看 AppUI/HTML/WebBridge/Server 结果 → 分享 `.miniapp` 或发布社区。桌面开发可通过局域网继续编辑和实时预览。

## J06 脚本到 Widget/自动化

小组件 Studio 新建模板 → 编写/运行 → 选择 Widget Family 预览 → 发布快照 → 在系统桌面添加 PythonIDE Widget。并行路径：在快捷指令中使用 `运行脚本`、传入参数/工作目录、等待或分离执行，再读取 `获取最后输出`。

## J07 远程运维

终端 → 添加服务器 → 选择密码/密钥 → 首次连接确认主机指纹 → SSH Terminal 或 SFTP → 上传/编辑文件 → Monitor 查看资源 → Deploy 配置远端路径/依赖/启动命令。网络失败、指纹变化、权限不足和断线重连是必须教程化的风险分支。

## J08 Git 交付

打开项目 → Git 初始化/克隆 → 查看状态与 Diff → Stage 文件或 Hunk → Commit → 选择分支/远端 → Pull/Push/Sync → 处理认证、主机信任或冲突。Discard、Hard reset、删除分支/Tag 等不可逆动作必须用图文风险提示，不作为漂亮的宣传镜头。

## J09 社区发现与发布

游客可搜索、按分类浏览、预览作品；需要网络。运行或安装后可保存到工作区。发布作品需要 PythonIDE 账号、资料、项目包/截图/说明并进入审核；个人中心查看待审、通过、驳回与获赞通知。

## J10 HTML 到公网网站

打开 HTML → `部署` → 使用 Apple 登录 → 项目扫描与修复问题 → 新建网站或关联已有网站 → 发布 → `打开`/`分享`。后续同一项目显示 `更新`；管理页可公开/下线、查看部署记录、回滚或删除。网站数量、流量、保留版本和隐藏品牌受免费/Pro 配额影响。

## J11 数据安全与恢复

文件删除 → `回收站` → 恢复或永久删除；外部文件夹/远端删除可能没有本地回收站。敏感文件可 `加密分享`，接收 `.enc` 后输入密码解密。App Lock 可用 Face ID/Touch ID 和自动锁定。应用数据管理器可查看、编辑、删除 MiniApp/Widget/WebBridge KV 数据或清空全部，后两者需明确风险提示。
