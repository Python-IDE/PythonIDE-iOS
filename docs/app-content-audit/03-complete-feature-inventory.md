# 完整功能清单（L0 → L1 → L2 → L3 → L4）

## 口径

L0 为“在 iPhone/iPad 完成 Python 工作流并交付结果”。以下经逐条校验为 12 个 L1、62 个 L2、162 个 L3。括号中的内容是 L4 状态/变体，不另重复计数。用户功能记录为 A/B；默认关闭的条件能力与 Debug/内部路径另列为 C/E，不混入普通用户 L3 数量。A–E 置信度定义见 `04-feature-evidence-matrix.md`。
