## P1：第二批重要教程

- Notebook Cell 与`全部运行`（F02.03）。
- 删除、回收站、恢复与永久删除（F01.04）。
- Debug 断点、单步、变量（F03.03.01/.02）。
- Widget Studio 到系统桌面（F06.01/.02）。
- SSH 首次连接与主机指纹（F08.01/.02）。
- SFTP 上传、编辑、下载（F08.03）。
- Git 从 Status/Stage/Commit 到 Push（F09.02/.03/.05）。
- Git 冲突解决（F09.06）。
- 发布社区作品与查看审核（F10.04/.03）。
- 登录、购买与恢复购买（F12.01/.02）。
- App Lock、应用数据清空与安全（F11.05）。

## P2：需要时制作

高级 Skill/MCP/Memory、桌面联机开发、WebDAV ETag、SSH Deploy、Shortcuts 参数化、原生模块真机教程、分支/Tag/Stash、工具箱长尾功能。优先响应实际客服/搜索数据，而不是预先录完。

## P3：无需单独制作/暂缓

直观设置、时间戳/进制转换、图标/主题微调、管理员页、Debug Preview、默认关闭后台 Agent、内部诊断、仅实现未确认入口的能力。
