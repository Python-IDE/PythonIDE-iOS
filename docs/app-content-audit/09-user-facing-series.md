# 面向用户的教程系列

## S1 第一次成功

- 目标：从安装到第一次可分享结果。
- 用户：完全新手；无需账号。
- 顺序：C-P0-01（可选认识产品）→ C-P0-02 → C-P0-05 → C-P0-08。
- 功能：F01.01、F02.01、F03.01/.02、F01.05。
- 可独立：报错恢复、分享。
- 不合并：包安装与第一次运行；会让首条过长。

## S2 把现有工作带进来

- 目标：导入、工作区、iCloud、外部文件夹、Share Extension。
- 用户：已有代码/文件；前置为理解首页。
- 顺序：F01.01.03 → F01.03 → F01.02 → F01.04。
- 可独立：回收站、加密分享。
- 不合并：外部文件夹授权与 WebDAV；后者是远端协议。

## S3 编辑、Notebook 与运行排错

- 目标：高效编辑、科学输出、Debug 和包管理。
- 顺序：F02.02 → F02.03 → F03.05 → F03.03。
- 可独立：Notebook、Debugger、包管理。
- 不合并：Debugger 与 Profiler；用户问题不同。

## S4 AI 协作与自动修改

- 目标：从安全对话到可验证项目修改。
- 前置：已有 Demo 项目；模型/额度可用。
- 顺序：F04.01/.02 → F04.03 → F04.04 → F04.05。
- 可独立：BYOK、Skill、MCP、Memory。
- 不合并：MCP OAuth 与首次 Agent 教程。

## S5 MiniApp 与桌面开发

- 目标：把脚本变成交互应用并迭代交付。
- 顺序：F05.01 → F05.02 → F05.03 → F05.04 → F05.05。
- 可独立：导入 `.miniapp`、隐藏 MiniApp、桌面连接。
- 不合并：局域网信任/同步故障与普通 MiniApp 创建。

## S6 Widget 与自动化

- 目标：把结果带到桌面、锁屏、Control Center 和 Shortcuts。
- 顺序：F06.01 → F06.02 → F06.03 → F06.04/.05。
- 不合并：iOS 16 旧 Widget 配置与 iOS 18 Control Center。

## S7 远程开发与 Git

- 目标：安全连接、传输、部署、提交和同步。
- 顺序：F08.01/.02 → F08.03 → F08.04；F09.01 → F09.02/.03 → F09.05 → F09.06。
- 可独立：WebDAV、SSH Keys、Stash。
- 不合并：SSH 指纹信任与 Git 冲突，两者都需要完整上下文。

## S8 发布与社区

- 目标：安装/发布社区作品，把 HTML 发布公网。
- 顺序：F10.01/.02 → F10.03/.04；F10.05 独立子系列。
- 前置：发布和网站管理需要账号；网站有配额/Pro 分支。
- 不合并：社区审核与网站部署，服务端状态完全不同。

## S9 数据安全、账号与购买

- 目标：恢复数据、保护隐私、理解权益、解决购买问题。
- 顺序：F01.04/F11.05 → F12.01 → F12.03 → F12.02。
- 账号注销、永久删除、Git Discard 必须各自独立，不能藏在“日常设置”长视频中。

## S10 Python 原生能力参考

- 目标：按权限/系统能力查找可运行示例。
- 结构：位置与传感器、媒体与识别、系统数据、安全与网络。
- 主要以图文 API Recipe 为主；真机操作按需求补 T4，不把几十个模块塞进一个视频。
