# 教程形式决策

## 原则

- T0：直观或只在别处顺带展示；T1：规则/限制/错误解释；T2：三步内静态操作；T3：手势或短流程；T4：跨页/有前置/易失败；T5：首次成功；T6：价值演示；T7：宣传素材。
- 每个 L3 的主形式写入 `feature-inventory.json`。下表给出 L2 默认及必须覆盖的例外；子功能继承默认，除非“例外”列另有说明。

| L2 | 主要形式 | 选择原因 / L3 例外 |
|---|---|---|
| F01.01 创建与导入 | T4 | 多入口和冲突；新建单文件 `.01` 可 T2，Share Extension `.03` 用 T3 |
| F01.02 组织/批量 | T3 | Swipe、Context Menu、多选必须看动作 |
| F01.03 工作区根 | T4 | iCloud/外部授权/迁移有状态分支 |
| F01.04 删除恢复 | T4 | 数据风险；永久删除规则另配 T1 |
| F01.05 查看交付 | T3 | 预览直观；加密分享需短流程与风险文字 |
| F02.01 编写代码 | T2 | 大多静态可解释；自动保存/冲突用 T1 |
| F02.02 导航查找 | T3 | Tab、查找、键盘操作视觉优先 |
| F02.03 Notebook | T4 | Cell 手势和运行状态跨步骤 |
| F02.04 预览 | T3 | 缩放、远程图片、Web 权限适合短录屏 |
| F02.05 个性化 | T2 | 设置位置和效果前后图足够 |
| F03.01 执行代码 | T5 | 第一次核心成功；参数另作 T2 |
| F03.02 输出交互 | T4 | input、Traceback、媒体结果容易误解 |

| F03.05 包管理 | T4 | 兼容性与失败原因高客服成本 |
| F04.01 对话上下文 | T4 | 工作区/模型/历史上下文影响结果 |

## 不应单独视频化

版本/配额/价格、支持格式、权限解释、错误码、隐私规则、删除保留期、兼容性列表全部优先 T1/T2。它们变化频率高，烧进视频会产生最高维护成本。
