# 内容发布验收标准与停止规则

## 发布前 Checklist

- [ ] 一个内容只解决一个明确问题，标题与结尾结果一致。
- [ ] 开始页面、登录/订阅/权限/网络状态已在脚本中写明。
- [ ] 每一步使用当前版本真实 UI 文案，不写“相应按钮”。
- [ ] 点击标记、长按时长、滑动方向和拖动终点清楚可见。
- [ ] 最终结果至少停留 1.0 秒；失败教程显示恢复后的成功状态。
- [ ] 不含真实姓名、邮箱、API Key、服务器 IP、文件路径、邀请/兑换码或通知内容。
- [ ] 飞行模式、勿扰模式、屏幕录制状态栏和系统弹窗符合镜头要求。
- [ ] 静音状态下仍可理解；字幕在手机屏幕上可读且不挡主控件。
- [ ] 设备、主题、字体、触点、背景与转场遵循同一模板。
- [ ] 删除、覆盖、清空、强制停止、Discard/Reset 等风险动作有明确警示。
- [ ] 不保留加载空转；真实等待超过 1 秒时剪切并标注。
- [ ] 不使用过度缩放、无信息转场或装饰性音效掩盖操作。
- [ ] 无旁白原子母片、字幕工程、封面和导出成片均已保存。
- [ ] 记录 App `CFBundleShortVersionString`、Build、iOS、设备、语言与录制日期。
- [ ] 由未参与剪辑的人按脚本从头复现一次，或开发者隔日复查。

## 统一规格

- 主版：iPhone 竖屏，中文简体，浅色模式；1080×1920 或等比例高分辨率。
- 原子素材：无旁白、无渠道文案烧录，首尾各留 12–15 帧；触点可单独开关。
- 教程字幕：每屏不超过两行；动作动词开头；真实 UI 文案用引号。
- 点击：短圆环 + 轻微缩放；长按：圆环持续填充；滑动：起点、轨迹、箭头。
- 局部放大：只在按钮小于成片安全阅读尺寸或手势区域不明显时使用。
- 旁白：只用于解释“为什么/风险/结果”，不逐字朗读屏幕。

## 明确的完成标准

满足以下四点即停止视觉返工：

1. 盲看一遍能说出从哪里开始、做了什么、得到什么。
2. 三名目标用户中至少两名无需口头补充即可复现，或开发者按 Checklist 独立复现无歧义。
3. 无隐私/事实/路径错误，风险动作和前置条件完整。
4. 阴影、圆角、动画速度、背景装饰的差异不影响阅读、品牌一致性或动作定位。

不因“触点圆环再小 2 px”“转场再慢 0.1 秒”“阴影更柔和”继续返工。只有影响用户理解、品牌模板一致性、可访问性、隐私或真实操作的差异才触发重录。

## 重录触发器

- 按钮文案、层级或入口路径改变。
- 起始 Demo 数据或最终结果不再可复现。
- 系统权限弹窗、付费门槛或账号流程改变。
- 触点与实际控件错位，或新设备安全区遮挡字幕。
- 功能状态从 Beta/Feature Flag 变为默认开启或下线。
- 只改颜色、圆角、图标微调且动作仍清楚：通常只更新封面/截图，不重录。
