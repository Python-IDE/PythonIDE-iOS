PythonIDE · Website publishing guide

How to publish an HTML website from iPhone

Write HTML in PythonIDE on your iPhone or iPad, preview it locally, and deploy it as a public HTTPS website. Share the link and anyone can open it in a browser.

Follow the steps ↓ Explore published sites ↓

Quick start

From an HTML file to a live website

Use a version of PythonIDE that includes the Deploy tab. You can create and preview files without signing in. Publishing and managing a site requires a PythonIDE account.

  1. 01

    Create or import an HTML project

    Tap the plus button to create an HTML file, or open a project from Files. Use index.html as your entry page. Keep CSS, JavaScript, and images in the project folder and reference them with relative paths such as ./styles.css.

  2. 02

    Check your page in Preview

    Edit the page in Code, then switch to Preview to check the text, buttons, and images. PythonIDE packages the project assets with your page, so you can skip creating or uploading a ZIP file yourself.

  3. 03

    Publish in Deploy and copy the link

    Tap Deploy Website, sign in if prompted, and confirm. Once the site is live, copy the HTTPS link and check it in a browser. You can update the same project later and keep its address.

After publishing

Website deployment FAQ

What can I host? Can I run a Python backend?

You can host static files such as HTML, CSS, browser JavaScript, images, and fonts. Website deployment does not run Python, Flask, Node.js, or databases. Visitors can read your public HTML and assets, so keep secrets and private files out of the project.

When does a site appear in the gallery?

Sites appear automatically once they’re live. A new site awaiting review is unavailable to visitors. During review of an update, the published version remains online. Taking a site offline pauses public access and removes it from the gallery.

How do I add a cover image?

Add <meta property="og:image" content="./cover.webp"> to the entry page’s <head>. Put a WebP, PNG, or JPEG file up to 1 MiB in the project and update the website.
